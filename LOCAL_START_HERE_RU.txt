DentalClinic — локальный пакет v4: Denta + Dashboard Reliability
================================================================

СТАТУС

- GitHub НЕ изменялся.

ГЛАВНЫЕ ИСПРАВЛЕНИЯ
1. Исправлена локальная ошибка TaskCanceledException при проверке JWT-сессии.
   - браузерские отмены запросов больше не должны ломать отладчик;
   - TokenVersion больше не проверяется отдельным SQL-запросом на КАЖДЫЙ API-вызов;
   - используется короткий безопасный кэш с немедленным обновлением при logout/смене пароля/revoke.

2. Ускорен админ-дашборд.
   - навигация и вкладки активируются ДО ожидания удалённой SQL-сессии;
   - основная таблица заявок больше не ждёт загрузку врачей;
   - скрытые разделы (аналитика, отзывы, врачи, профиль) загружаются лениво при первом открытии;
   - скрытая аналитика не создаёт пачку API-запросов при старте страницы;
   - при реальном открытии «Аналитики» данные перечитываются из БД, а после изменений заявок кэш статистики помечается устаревшим;
   - серверная аналитика объединяет несколько отдельных SQL COUNT-запросов в один агрегатный запрос;
   - Chart.js загружается асинхронно и больше не блокирует DOMContentLoaded/вкладки.

3. Ускорен кабинет пациента.
   - убран top-level await: вкладки работают сразу, даже пока сервер проверяет сессию через удалённую БД;
   - сначала загружаются записи пациента, вторичные данные загружаются после;
   - отзывы пациента загружаются только при открытии вкладки «Отзывы»;
   - удалена блокирующая зависимость кабинета от Google Fonts.

4. Добавлены пределы ожидания.
   - SQL-команды ограничены 20 секундами в developer-конфигурации;
   - обычные API-запросы в браузере имеют таймаут 20 секунд;
   - проверка серверной сессии — максимум 25 секунд;
   - одинаковые одновременные GET-запросы объединяются в один in-flight запрос.

5. Локальные фоновые jobs отключены по умолчанию в Development.
   Это предотвращает лишние запросы к удалённой базе при локальной отладке.
   Production-поведение не меняется: без Development они включены по умолчанию.

6. Сохранены все предыдущие исправления Denta.
   - intelligent DB/site routing;
   - structured replies;
   - исправление /undefined у кнопок-ссылок;
   - приветствия и общие вопросы;
   - услуги/цены/врачи/седация;
   - оригинальная полная карточка Dr. Лилит Рейнер снова сопоставляется с DB-записью «Рейнер Лилит».

КАК ЗАПУСТИТЬ
1. Распакуйте архив в новую папку.
2. Откройте DentalClinic.csproj в Visual Studio.
3. Убедитесь, что установлен .NET 10 SDK.
4. В терминале из корня проекта:

   dotnet restore
   dotnet build
   dotnet test
   npm run test:js

5. Затем F5.
