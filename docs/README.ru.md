## Языковая политика

Английский является каноническим языком GitHub README и инженерного справочника. Русские версии доступны в `README.ru.md` и соответствующих файлах непосредственно в `docs/`.

При изменении поведения обновляйте английский документ и русский перевод в одном pull request. Команды, маршруты, ключи конфигурации и идентификаторы кода при переводе не меняются.

## Как сохранять документацию достоверной

- Описывайте только поведение, подтверждённое текущим кодом, конфигурацией, миграциями или CI.
- Явно помечайте планы и исторические снимки.
- Не добавляйте production credentials, реальные данные пациентов, приватные записи клиники и необработанные логи/скриншоты.
- Перед merge проверяйте внутренние ссылки и JSON-примеры.
- Следуйте требованиям [CONTRIBUTING.md](../CONTRIBUTING.md).
