# 📡 Справочник REST API

Базовый путь: `/api`. Формат данных — JSON. Эндпоинты, требующие авторизации, помечены 🔒
(заголовок `Authorization: Bearer <token>`), эндпоинты только для администратора — 🔒👑.

> В режиме разработки (`Development`) доступна интерактивная Swagger-документация по
> адресу `/swagger` — там же можно опробовать запросы прямо из браузера.

## Auth — `/api/auth`

| Метод | Путь | Доступ | Описание |
|---|---|---|---|
| POST | `/register` | публичный | Регистрация пациента |
| POST | `/login` | публичный | Вход пациента, возвращает JWT |
| POST | `/admin/login` | публичный | Вход администратора, возвращает JWT |
| GET | `/profile` | 🔒 пациент | Данные своего профиля |
| GET | `/admin/profile` | 🔒👑 | Данные профиля администратора |
| PUT | `/profile` | 🔒 пациент | Обновление профиля |
| PUT | `/change-password` | 🔒 | Смена пароля |

Вход/регистрация ограничены политикой `auth` — не более 8 запросов в минуту с одного IP
(защита от подбора пароля).

## Notification — `/api/notification`

| Метод | Путь | Доступ | Описание |
|---|---|---|---|
| GET | `/` | 🔒 | Свои уведомления |
| GET | `/unread-count` | 🔒 | Счётчик непрочитанных |
| PUT | `/{id}/read` \| `/read-all` | 🔒 | Отметить прочитанным |
| DELETE | `/{id}` \| `/` | 🔒 | Удалить одно / все уведомления |

**Realtime:** те же события приходят мгновенно через SignalR-хаб `/hubs/notifications`
(см. `wwwroot/assets/js/services/realtime.js`) — REST используется для начальной загрузки и
как резерв, если WebSocket-соединение недоступно.

## Chat (AI-ассистент) — `/api/chat`

| Метод | Путь | Доступ | Описание |
|---|---|---|---|
| POST | `/` | публичный | Отправить сообщение боту, получить полный ответ (лимит 15/мин) |
| POST | `/stream` | публичный | То же самое, но потоковый ответ (Server-Sent chunks) |
| POST | `/tts` | публичный | Озвучить текст через ElevenLabs |
| GET | `/admin/sessions` | 🔒👑 | Последние сессии диалогов с ботом |
| GET | `/admin/stats` | 🔒👑 | Статистика по чат-боту за период |

Контекст ответов бота (цены, врачи) собирается «на лету» из БД сервисом
`ChatKnowledgeService` с кэшированием — при изменении прайса через админку бот сразу знает
актуальные цены.

### Формат ошибок

Необработанные исключения возвращаются в едином формате (см. `Program.cs`):

```json
{ "message": "Произошла внутренняя ошибка сервера" }
```

Превышение лимита запросов (`429 Too Many Requests`):

```json
{ "message": "Слишком много запросов с вашего IP. Попробуйте через минуту." }
```
